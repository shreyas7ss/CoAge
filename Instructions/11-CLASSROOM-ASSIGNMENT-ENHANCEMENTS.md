# Classroom, Materials, and Assignment Workflow Enhancements

## Goal

Extend CoAge so faculty can create a classroom around a subject, share study materials, and create assignments either manually or with AI assistance. Students sign up with a student role and join a faculty classroom using its code. Every assignment receives an AI-generated marking rubric, regardless of who authored the assignment.

## Requirements

1. **Role-based signup**
   - Add a signup option to the login page.
   - New users choose either Faculty or Student when registering.
   - Keep role-based access checks in place after authentication.

2. **Subjects and study materials**
   - Faculty can create a subject/classroom.
   - Faculty can add study materials to a subject for students to use as assignment context.

3. **Assignment authoring**
   - Faculty can create an assignment manually.
   - Faculty can ask the AI workflow to draft an assignment using the subject's study materials.
   - Faculty reviews and confirms AI-generated assignment content before it is published.

4. **Rubric generation**
   - Every assignment receives a rubric generated by the agent, whether the assignment was drafted by AI or authored manually.
   - The rubric breaks down marks into criteria with descriptions and maximum marks.
   - Validate that criterion marks are non-negative and sum to the assignment total; faculty can review the proposed rubric.

5. **Classroom enrollment**
   - Faculty classrooms have a join code.
   - Students can join a classroom by entering that code.
   - Enrollment connects students to the faculty and subject, and controls access to its materials and assignments.

## Implementation notes

- Reuse the existing user, course, assignment-setup agent, authentication, and rubric models where practical.
- Keep AI-generated content as a draft until faculty confirms it.
- Add schema migrations and API/UI changes for any new persisted concepts.
- Preserve student/faculty data isolation and validate classroom membership on student-facing resources.

## Acceptance criteria

- A visitor can register as either faculty or student and then sign in.
- Faculty can create a subject and add study material.
- Faculty can generate an assignment draft from study material or author one manually.
- Both assignment paths produce a validated rubric with a mark breakdown.
- Faculty can share a classroom code; a student can join with that code and access the classroom's published content.
